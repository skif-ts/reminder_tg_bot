# Telegram Reminder Bot

Telegram-бот для создания и отправки напоминаний.

Проект написан на **Go** и предназначен в первую очередь для обучения Go на практическом проекте.

## Возможности

* создание напоминаний обычным текстом;
* создание напоминаний голосом;
* распознавание голоса через локальный **Whisper.cpp**;
* поддержка относительного времени:

  * `через 10 минут`
  * `через 2 часа`
  * `через неделю`
  * `через полчаса`
* поддержка конкретного времени:

  * `15:40`
  * `15.40`
* поддержка даты:

  * `02.10.2026`
  * `02.10.2026 19:40`
* естественные формулировки:

  * `завтра утром купить молоко`
  * `послезавтра вечером позвонить маме`
* повторяющиеся напоминания:

  * `каждый час`
  * `каждый день`
  * `каждую неделю`
  * `каждый месяц`
  * `каждый год`
  * `по будням`
  * `в выходные`
* просмотр списка напоминаний через `/list`.

## Стек

* Go
* Telegram Bot API
* `go-telegram-bot-api`
* Whisper.cpp
* FFmpeg

## Требования

Для запуска проекта необходимы:

* Go
* Telegram Bot Token
* FFmpeg
* Whisper.cpp
* модель Whisper `ggml-base.bin`

Для голосовых сообщений в текущей версии используются пути:

```text
C:\cpp\whisper.cpp\build\bin\Release\whisper-cli.exe
C:\cpp\whisper.cpp\ggml-base.bin
```

Если Whisper.cpp установлен в другом месте, пути необходимо изменить в `voice.go`.

## Установка

### 1. Клонировать репозиторий

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПРОЕКТА>
```

### 2. Установить зависимости Go

```bash
go mod download
```

### 3. Настроить Telegram Bot Token

Не храните токен непосредственно в исходном коде.

В Windows CMD можно создать переменную окружения:

```bat
setx REMINDER_BOT_TOKEN "ВАШ_TELEGRAM_BOT_TOKEN"
```

После выполнения `setx` необходимо закрыть текущий терминал и открыть новый.

Проверить наличие переменной:

```bat
echo %REMINDER_BOT_TOKEN%
```

В коде токен читается следующим образом:

```go
token := os.Getenv("REMINDER_BOT_TOKEN")
```

### 4. Установить FFmpeg

FFmpeg должен быть доступен из командной строки:

```bat
ffmpeg -version
```

Если команда выполняется успешно, Go-программа сможет использовать FFmpeg для преобразования голосовых сообщений.

### 5. Установить Whisper.cpp

Whisper.cpp должен быть собран и доступен вместе с моделью.

Проверить запуск:

```bat
C:\cpp\whisper.cpp\build\bin\Release\whisper-cli.exe ^
  -m C:\cpp\whisper.cpp\ggml-base.bin
```

При необходимости измените пути в `voice.go`.

## Запуск

После настройки окружения:

```bash
go run .
```

При успешном запуске в консоли появится сообщение о запущенном боте.

## Примеры

Создание напоминания:

```text
12:30 позвонить маме
```

```text
завтра утром купить молоко
```

```text
через два часа проверить почту
```

Повторяющееся напоминание:

```text
09:00 принять лекарство каждый день
```

Список напоминаний:

```text
/list
```

или:

```text
/l
```

Также бот может принимать голосовые сообщения. Голос скачивается из Telegram, конвертируется в WAV через FFmpeg и распознаётся локальным Whisper.cpp.

## Структура проекта

```text
.
├── main.go       # Telegram-бот, напоминания и scheduler
├── parser.go     # разбор времени и повторений
├── voice.go      # загрузка и распознавание голосовых сообщений
├── go.mod
└── go.sum
```

## Текущий статус

Проект находится в разработке.

Сейчас хранилище напоминаний работает в памяти процесса. После перезапуска бота созданные напоминания теряются.

В дальнейшем планируется добавить постоянное хранилище, удаление и редактирование напоминаний, а также дальнейшее улучшение обработки естественного языка.
